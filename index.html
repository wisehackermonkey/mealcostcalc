How it is calculated

  1. Budget after gas and labor = estimated budget - monthly gas - (weekly labor x 4).
  2. Buffer reserve = that amount x buffer %. The rest is spendable.
  3. Cost per meal = spendable / (meals per month + snacks per month x snack %).
  4. Cost per snack = cost per meal x snack %.
  5. Snack budget = snacks per month x cost per snack.
